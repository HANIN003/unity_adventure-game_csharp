# Adventure Game in Unity (C#)
A Track 1 project for Parallel Languages, created by Nathan Hanisch.  
This project focuses on learning C# independently and applying it within Unity to build a functional 2d adventure game. The game will include player movement, item collection, scoring, enemy behavior, and a win condition.

## Project Goals
- Learn C# and apply object-oriented design, type systems, and event-driven behavior.
- Build a complete Unity adventure game from scratch.
- Demonstrate encapsulation, polymorphism, and modular architecture.
- Use VS Code and GitHub for development and version control.

## Tools & Technologies
- Unity (2022 or later)
- C#

## How to Run
1. Clone the repository.
2. Open the project folder in Unity Hub.
3. Open the `MainScene` and press Play.
